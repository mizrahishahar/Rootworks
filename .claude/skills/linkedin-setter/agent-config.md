# The agent config

A client's LinkedIn setter agent runs with this skill loaded; the craft is already in the room. **The config carries only what the skill cannot know: this client's specifics.** Restating the skill's own rules in a config is the failure mode; a restated rule drifts against the skill the next time the skill moves.

What belongs, the kind of thing and nothing bigger:

- A specific proof to always mention, and where it leads.
- A specific thing to never mention (a price, a claim, a name, a competitor).
- The specific assets to use in the chase, with their real links.
- A tone or behavior delta this client insists on.
- A boundary specific to this client: what the agent leaves for a human here.

The test for every line: **would this line be wrong for a different client?** True for everyone means it belongs in the skill. Specific to this client means it belongs here and nowhere else.
