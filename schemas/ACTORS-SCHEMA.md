# ACTORS-SCHEMA

An actor is a source: it scrapes a signal on a schedule and its task's webhook hands the run to a Rootflow's door. Ours or rented, every actor has one card. This changes rarely.

## Tree

```
actors/
  <platform>/
    <Actor>/
      card.json
      src/          our source, deployed from here (apify push); absent for a rented actor
  INDEX.md
```

`INDEX.md` is generated by `scripts/actors/index.js` from the cards.

## Card

```json
{
  "name": "Fresh Service Complaints",
  "platform": "apify",
  "ours": true,
  "feeds": "Discover Reviews Companies, door POST /webhook/discover-reviews-companies, payload { play, resource }",
  "schedule": "daily 05:00 UTC; task max charge $2",
  "task": "",
  "description": "one sentence"
}
```

`feeds` names the Rootflow and the door the task's webhook posts to. `task` is the scheduled task's id in the platform's console, filled by the Operator. A rented actor has a card and no `src/`.
