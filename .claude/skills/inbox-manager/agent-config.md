# The agent config

A client's inbox agent runs with this skill loaded. The craft, the shapes, the checklists, the voice: it already has all of it. **The agent config carries only what the skill cannot know: this client's specifics.** Restating anything the skill already teaches is the failure mode, because a restated rule drifts against the skill the next time the skill moves.

What belongs in a config, the kind of thing and nothing bigger:

- A specific proof to always mention, and where it leads.
- A specific thing to never mention (a price, a claim, a name, a competitor).
- The specific assets to use in follow-ups, with their real links, and which rounds they belong to.
- A tone or behavior delta this client insists on.
- A boundary specific to this client: what the agent leaves for a human here.

The test for every line: **would this line be wrong for a different client?** If it would be true for everyone, it belongs in the skill, not the config. If it is specific to this client, it belongs here and nowhere else.
