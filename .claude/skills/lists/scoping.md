Teaches: the market read and the first call of a build. How many lists a brief warrants, how big each should be, where the TAM lives, and what comes after a list runs dry.

# Scoping

The first call, and the one that shapes everything downstream: how many lists does this brief warrant, and how does each open? One number and a spec per list. Each becomes one pull, one tag on the base, and usually the spine of its own campaigns.

## What makes one list

One sentence, specifically true for everyone the list should return. If the sentence has to go generic, there are two lists. Narrow enough has the same test from the copy side: one specific copy line is true for everyone on the list.

## Read the brief first

A build arrives as a hand-off: the offer, who to reach, which source opens the build, any domains already in hand, prior results. The brief names the opening, company-first (a discovery source) or contact-first (a contact database). The source's own skill shapes the query; this call carries the judgment that stays constant across sources: how many lists.

## Sizing: the ratios that back-calc a list

Directional; niches swing them hard (trades run far hotter than SaaS):

- about 1 meeting per 5,000 sends, 1 positive per 750, 1% reply, bounce under 3%. Judge nothing under about 5,000 sends; trust an angle at 10 to 15 positives.
- build 1,500 to 2,500 leads per test cohort, 1,000 to 2,000 per native segment, and hold 10,000 to 15,000 verified to run a month without re-sourcing.

## Where the TAM lives

- **Match the source to the niche.** Profile-anchored tools cover a fraction of blue-collar, SMB, private and international markets; web-indexed discovery reaches the long tail. Never trust one source to hold a whole market.
- **The floor:** under about 1,000 reachable prospects, cold email breaks; pivot toward ABM or calling.
- For firms under about 10 employees, add public and role emails alongside personal ones.

## Depth vs breadth

Thin TAM wins on depth: more enrichment, sharper personalisation, more touches per lead. Wide TAM wins on volume and segmentation, and enrichment stays lighter.

## Refill

Decay is physics: reply rates fall across a sequence, and re-hitting leads decays them faster. The fix is fresh leads, not copy tweaks, and the refill is built before the pool runs dry. The ladder, by what has already run: segment harder, widen a filter or the geo, mine the client book for profitable sub-verticals, a new source, recycle last.

## Name the segments each list implies

A two-list build is at least two campaigns, and the pulls must carry what the intended segments will select on. Naming them at scoping secures the variables; designing segments only after ingest forces expensive base fixes. The full set still waits for the base and the real distribution.

## How to show it

One real markdown table, one row per list, never inside a code fence:

| List | The audience, one sentence | Source and opening | Est. size | Variables to ride with the pull |
|---|---|---|---|---|

Under it: the implied segments per list, and any judgment call worth flagging as one labeled line each.
