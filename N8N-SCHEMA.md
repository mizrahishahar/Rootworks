# N8N-SCHEMA

A machine is one or more n8n workflows doing one job. It is one of six types, it sits in that type's folder, it has one card. This changes rarely.

## Types

| Type     | Definition                                                                                               | Folder           |
| -------- | -------------------------------------------------------------------------------------------------------- | ---------------- |
| Rootflow | adds to a client Clayroots base. (our version for Clay Templates)                                        | `n8n/rootflows/` |
| Deploy   | moves rows from a view into a sender and stamps them                                                     | `n8n/deploys/`   |
| Handler  | one event from outside, one lead moved                                                                   | `n8n/handlers/`  |
| Manager  | reads state on a schedule, reports to Slack, changes what its permissions allow. Works on set standards. | `n8n/managers/`  |
| Helper   | called by the others, no run/logs of its own                                                             | `n8n/helpers/`   |
| Add-on   | fired by a machine at a hook, one more thing                                                             | `n8n/addons/`    |

`n8n/archive/` is off. A workflow that is off and has no card lands there; a workflow that is on and has no card is flagged UNAPPROVED in the index.

## Tree

```
n8n/
  <type>/
    <Machine>/
      card.json
      <Workflow>/
        workflow.json
        nodes/*.js
  archive/<Workflow>/
  INDEX.md
```

`INDEX.md` is generated by the pull from the cards and the webhook nodes: machine, type, door, description, on.

## Card

```json
{
  "name": "Enrich Contacts",
  "type": "rootflow",
  "workflows": { "PLTNYqqoYfrt9ypd": "Enrich Contacts", "WG46cPFf6jx91aVq": "Enrich Contacts Chunk", "rc2IqbRdeTHjLP6F": "Enrich Contacts Writer" },
  "writes": "People, Companies",
  "description": "Finds people for every company in a Companies view from Blitz, GetLeads, QuickEnrich and Supersoniq, writes them into People linked to their company, then hands Not Waterfalled to Enrich Emails."
}
```

`name`, `type`, `workflows`, `description`, and one field by type:

| Type | Field |
|---|---|
| rootflow | `writes`: the tables it adds to |
| deploy | `sender` |
| handler | `event` |
| manager | `may_change` |
| helper | `called_by` |
| addon | `hook` |

The card is the approval: written after the Operator said yes; the push creates a workflow only when its card names it. A new workflow goes on the card under its name as the key; the push fills the id.

## Supported senders

A sender is supported when it has a Deploy, a Handler, and a line in the Campaigns Manager. PlusVibe, Alta, Email Bison.
