# spintax

Add spintax to an approved sequence, without touching its meaning.

Loads `cold-email-copywriter`. Runs after `write-campaign`, before `deploy-to-plusvibe`.

## Rules

- **Three options to a spin, never two.** `{{random|Hey|Hi|Hello}}`.
- **Spin four to six slots per touch**, not one. A spun greeting alone is decoration: the body still lands byte-identical on every send. Spin the greeting, the connectives, the verbs, the soft phrasing around the ask.
- **Never spin substance.** Not a number, not a name, not the guarantee, not the meaning of the CTA. A spin that shifts meaning is worse than no spin.

## The check that matters

**Every option gets substituted back into its full sentence and read.** An option that reads fine alone can produce broken English inside its host sentence, and that is exactly how trust in this command was lost once already. If you have not rendered it, you have not offered it.

## Done when

The sequence is shown with the spins in place, plus one rendered example per touch using different picks, so the Operator reads what a real recipient would get.
